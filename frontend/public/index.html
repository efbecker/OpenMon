Deploy do Banco de Dados (Servidor 2 — TimescaleDB)

Informe o endereço e as credenciais SSH do Servidor 2 (Debian 13 ou superior). O OpenMon instala remotamente o PostgreSQL 17 e o TimescaleDB dos repositórios oficiais, aplica o tuning pelo hardware, cria o schema com hypertables, continuous aggregates e retenção de 5 anos, ativa TLS e libera o banco só para este servidor no pg_hba.conf.

Segurança de credenciais Usadas só durante o deploy · nunca gravadas Chave SSH do Servidor 2 conferida antes do envio da senha

Token de instalação

O token foi exibido no final do instalador (curl). Ele também está no Servidor 1 em /var/lib/openmon/setup.token (sudo cat /var/lib/openmon/setup.token).

Banco de dados já provisionado

O assistente de instalação foi encerrado. Para refazer o deploy, rode o instalador novamente no Servidor 1 com --new-setup-token.
